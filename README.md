# Sentinel Prep AI

Landing Page Design Prompt

Create a premium, modern, highly professional landing page for an MCA/M.Tech project titled:

“AI-Driven Army Recruitment Preparation and Personalized Guidance System”

The website should have a modern Indian Army-inspired visual identity, combining military discipline with futuristic AI technology. The design must look like a real-world defence technology platform rather than a basic academic project.

Overall Visual Style

Premium defence-tech aesthetic

Dark military-inspired theme

Sophisticated, minimal and professional UI

Cinematic atmosphere

3D visual elements

Smooth animations and transitions

Glassmorphism panels

Subtle glowing effects

High-quality typography

Responsive design for desktop, tablet and mobile

Avoid an overly aggressive or game-like military appearance

Color Palette

Use a sophisticated palette based on:

Deep charcoal / near-black background

Military olive and muted green accents

Dark forest green

Warm off-white text

Subtle gold/brass highlights

Very limited red accents for alerts or important indicators

Keep the colors elegant and restrained.
